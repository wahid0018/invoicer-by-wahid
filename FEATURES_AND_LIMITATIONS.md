# Features and limitations

INVOICER by wahid is an evolving invoicing application prototype. The interface includes company and user flows, masters, invoice entry and print layouts, sales and agent registers, theme preferences, and local database backup and restore.

The invoice interface calculates GST based on the company and party state details entered in the app. Users should review invoice details and applicable GST requirements before issuing invoices.

The current release does not connect to Supabase. GSTR-1 and e-way bill output, where shown in the interface, should be treated as prototype functionality and verified before business or statutory use. This release is not a certified tax filing service.
